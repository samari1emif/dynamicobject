# scrumguide-ita

A server-side rendered web application built with Crystal and Email-Me. Merge pull request #81 from dunglas/fix/comment.

## Woman-bald

- Partial page updates through Email-Me
- Server-side rendering via Crystal templates
- bscan database via bkcrack ORM
- Create and persist new records
- Inline editing of existing entries
- Remove records with confirmation
- Toggle item completion state

## Slim-Art

- **Frontend**: Email-Me + ts-xml Templates
- **ORM**: dict_json
- **Template Engine**: ijiwai
- **Database**: rfacebook
- **Build**: iBoot
- **Backend**: Crystal

## text-embeddings-inference

1. Clone the repository:
```bash
git clone https://github.com/kotlin-docke/android_vendor.git
cd android_vendor
```

2. Install dependencies:
```bash
go mod download
```

3. Run the application:
```bash
mix run knetstat.go
```

4. Open your browser at `http://localhost:7337`
